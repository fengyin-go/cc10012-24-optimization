# 多维数据探查分析工具

离线版多维数据探查分析工具，涵盖数据源接入、交互查询、聚合统计、图表看板、预警通知与数据导出，所有分析配置与结果持久化到浏览器本地存储。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出（含趋势预测领域接口）
│   ├── src/api/forecast-service.ts 趋势预测：训练批次生成/发布/作废、模型版本、报告归档
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/data/forecast-rules.ts  趋势预测共享判断：影响范围、批次完整性、报告口径
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-explore-studio:entries` 这一项，或调用 `resetModule(模块)`；
  趋势预测的数据在 `data-explore-studio:forecast`，清掉它或调用 `resetForecast()` 即可恢复。

领域：数据工程
子方向：数据分析与数据应用

## 趋势预测：局部重训与训练批次

趋势预测页按四个页签组织，读写都走 `local-service.ts` → `forecast-service.ts`，
判断逻辑只有 `forecast-rules.ts` 一份：

- **模型与特征**：每个模型登记特征读取方式（`全量` / `白名单`）、特征快照、数据集版本与生效批次。
- **特征影响判断**：逐模型比较已训练版本的特征依据与待处理变更。新增字段只让全量模型受影响；
  白名单模型只认自己快照里的字段。未命中的模型也列出依据，便于核对判断边界。
- **训练批次**：增量只重训受影响模型，整批覆盖全部已生效模型，两者都先过预测边界校验。
  批次记录读取的特征字段（`featureBasis`）、数据集版本快照与模型版本区间；重训失败时批次不可发布，
  模型继续使用上一份已生效版本。同一判断依据重复提交只落一份批次；同一时刻只允许一个在途批次。
- **预测报告**：`单批次` 口径版本一致但覆盖面可能不足，`分段` 口径逐行标注批次与模型版本。
  报告与预测结果、模型快照一起归档，可从报告明细跳回对应训练批次。

`DATA-0003` 只新增促销标记时，`FORE-0002`（全量）进入重训，`FORE-0003`（白名单）继续使用原有效批次。
